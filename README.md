# FF Title Card Generator

## Project Goal
Franklin Furnace Archive, Inc. publishes access copies of performance art documentation to Vimeo for free, public access. The generation of access copies with requisite title cards and watermarks
was once a very labor intense process. The title-card creation relied solely on proprietary software Adobe Photoshop. This required training interns many-times on the use of Photoshop and 
template Photoshop file often changed over many iterations of adjusting a name to fit into the alignment that FF had been historically using. To automate some of this process and also to ensure
that FF is not reliant on proprietary software (that keeps becoming more expensive every year), this Title Card Generator GUI software was created. 

### Dependencies 
- Python 3.12 or later
- ImageMagick
- Mac OS

### Usage
- From the 'dist' folder, copy the _TitleCardGenerator.app_ into your Mac OS Applications folder.
- Open the _TitlecardGenerator_ application from the Applications folder.
- Within the opening GUI, enter information as required. 
<img width="501" height="582" alt="Screenshot 2026-09-04 at 11 28 29 AM" src="https://github.com/user-attachments/assets/ef2bbc11-95d1-4874-924a-7feb14aa80ad" />

- **Note**: Make sure to atleast have a Artist Name, Title and Year. Sub-Title is optional.
- Hit Generate!
- You will see a pop-up confirming that the titlecard has been generated and saved to the Desktop.
